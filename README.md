# UVC Tool

Android-застосунок для USB-ендоскопів і простих UVC-камер (перевірено на
`349c:0411 Generic HD camera`). Працює з будь-якою UVC-камерою, що віддає YUYV;
MJPEG — у планах. Чиста Java + власний нативний
шар на libuvc/libusb, без сторонніх «камерних» обгорток.

## Можливості

- живе відео з камери через OTG (можна через хаб), автозапуск при підключенні;
- кілька камер — вибір зі списку; тап по статусу вгорі — вибір камери й режиму
  (роздільність і частота кадрів), режим запам'ятовується для кожної камери;
- дзеркало (для бокової насадки-дзеркальця), поворот на 90°;
- баланс білого повзунком «холодніше / тепліше»;
- перемикач «фото / відео»: кнопка на екрані й кнопка на кабелі камери роблять
  знімок або запускають/зупиняють запис H.264; звуковий сигнал на кожну дію;
- вбудована галерея: перегляд фото й відео, зум щипком до 10×, покадровий
  перегляд відео;
- книжкова і альбомна орієнтація, екран не гасне, поки застосунок відкритий;
- сам перевіряє оновлення на GitHub і пропонує встановити нову версію.

Фото зберігаються в `Pictures/UvcTool`, відео — в `Movies/UvcTool`.

## Встановлення

1. На телефоні відкрий сторінку
   [остання версія](https://github.com/uw5eg0/uvc-tool/releases/latest)
   (або відскануй QR-код вище) і завантаж файл `UvcTool-vX.Y.Z.apk`.
2. Відкрий завантажений файл. Android попросить дозволити встановлення з
   браузера — дозволь (це потрібно лише один раз).
3. Підключи ендоскоп через OTG-перехідник. При першому запуску дай дозвіл
   «Камера» і доступ до USB-пристрою — без дозволу «Камера» Android 10+ не
   пускає застосунок до USB-камер.

### Оновлення

Застосунок раз на добу перевіряє, чи вийшла нова версія, і показує на головному
екрані плашку «Доступна версія …». Натисни її → «Оновити»: застосунок
завантажить APK з цього репозиторію і запропонує встановити його поверх.
Вручну: кнопка меню у правому верхньому куті → «Перевірити оновлення». Там же «Поскаржитись» — звіт з логом і даними про телефон на GitHub.

Альтернатива — [Obtainium](https://github.com/ImranR98/Obtainium) з адресою
`https://github.com/uw5eg0/uvc-tool`.

### Дозволи

- **Камера** — без неї Android не дає доступ до USB-камер (сама камера телефона
  не використовується);
- **Фото й відео** — щоб галерея бачила і файли, збережені попередніми
  встановленнями (необов'язково);
- **Інтернет / встановлення застосунків** — лише для перевірки й встановлення
  оновлень з GitHub. Жодних інших мережевих запитів, аналітики чи реклами немає.

## Збірка

Потрібні JDK 17, Android SDK, NDK 26.1.10909125 і CMake 3.22.

```sh
git clone --recursive https://github.com/uw5eg0/uvc-tool.git
cd uvc-tool/android
./gradlew assembleDebug
```

Реліз: підняти `versionCode`/`versionName` в `android/app/build.gradle.kts`,
закомітити й поставити тег `v<versionName>` — GitHub Actions збере підписаний APK
і опублікує реліз (`.github/workflows/release.yml`). Збірка без оновлювача
(наприклад, для F-Droid): `UVC_SELF_UPDATE=false ./gradlew assembleRelease`.
